# أرشيف ملفات SQL القديمة

هذه الملفات هي سكربتات migration/fix تم تطبيقها سابقاً على قاعدة البيانات الحية (واحدة تلو الأخرى بمرور الوقت). محفوظة هنا للرجوع التاريخي فقط — **لا تُشغَّل من جديد**.

المرجع الحالي والدقيق لبنية قاعدة البيانات بأكملها هو ملف `schema_all.sql` في جذر المشروع، وهو مبني مباشرة من نسخة احتياطية فعلية لقاعدة البيانات الحية (وليس من تجميع هذه الملفات القديمة).

عند الحاجة لإنشاء قاعدة بيانات جديدة من الصفر: استخدم `schema_all.sql` فقط.
